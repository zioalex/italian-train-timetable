Data Flow Example
User searches: Milano Centrale → Roma Termini, tomorrow 9:00
Frontend calls GET /api/search?from=milano&to=roma&date=2024-01-15T09:00
Backend queries all active adapters in parallel
Trenitalia Adapter → ViaggiaTreno /soluzioniViaggioNew/...
Trenord Adapter → checks if route is regional (unlikely for this route)
Results merged, sorted by departure time
Each result enriched with real-time delay data
Alerts checked for affected lines
